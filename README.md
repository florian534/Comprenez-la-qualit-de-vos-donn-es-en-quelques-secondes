# Comprenez-la-qualit-de-vos-donn-es-en-quelques-secondes
Application web d’audit et d’exploration de données avec Flask et DuckDB : profilage (schéma, valeurs manquantes, doublons, cardinalité), statistiques et détection d’anomalies. Intègre un agent IA Text-to-SQL sécurisé avec Ollama, un RAG hybride sur PDF et l’évaluation du LLM et de la recherche documentaire..
